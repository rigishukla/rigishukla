#### 🧩 System Highlights (Rekon Tender)

| Layer | What I Built |
|---|---|
| **Data Pipeline** | Custom web scrapers for GeM, CPPP & IREPS — ingesting thousands of government tenders |
| **AI Classification** | Automated tender categorization, procurement-type tagging, and smart match scoring |
| **AI Chat** | Claude-powered conversational tender analysis and business profile insights |
| **Database** | 30+ PostgreSQL migrations — RLS policies, RPC functions, full lifecycle tracking |
| **Payments** | Razorpay integration with webhook-driven subscription management |
| **SEO** | Dynamic sitemaps, programmatic landing pages, robots.txt — built for organic discovery |
| **Admin** | Secure admin dashboard with analytics, scrape-run monitoring, and data quality tools |
